# Agent 运行记录与每日持仓

六项能力从本次上线开始记录新版本；已有订单、成交和研究档案保留。已有 ETF/Stock 运行结果只读导入，不补造未保存的历史版本。

- 设置：本机 ETF 实盘、网站/下载版、Stock Monitor、Finance 默认与每月设置按作用范围分别记录。观察到的设置不会被当作新的用户授权；界面明确确认的 Finance 修改另记确认事件。
- 运行进度：ETF 账户读取、决策、订单结果、报告数据和消息回执可按同一交易窗口查阅。记录不能驱动策略或绕过核验。
- 通知：独立只读服务负责发送；订单与发送状态分开。PENDING 可以发送；没有确定回执的 SENDING/UNKNOWN 不自动重发，也不重跑订单。
- 时效：行情收盘日期、账户查询时间、参考报价时间分别标明。收盘后允许报告券商最近报价，资金核验未通过则可用自有资金显示待确认。
- 诊断：认证、估值、过期数据、报告读取及消息不明状态有固定说明；不自动改规则、复制凭据或放松门槛。
- Stock 历史：按股票和关键词检索已保存的研究与原始证据日期；仅用于回顾，不接入评分、Entry/Exit 或仓位分配。

## 每日持仓

交易日美东 15:31 起，待交易窗口退出后发送独立一条。当天开机/联网恢复后至美东 20:00 前补发一次；已发送或送达不明时不重发。独立服务名称 `com.averra.etf.reports`，固定 `live=False`，不能调用订单预检查或下单接口。

报告保留账户核实、QQQ/SMH 股数/市值/比例、现金比例、券商总资产、今日额度、自有资金、市场行情、评分、暂停状态和独立市场回撤观察。不展示旧版虚拟月度额度；今日剩余额度不是账户现金或可买金额。

## 查看

Stock Telegram：`/ops`、`/settings_history`、`/research_history AMD`、`/research_history AMD 风险`。原 `/history` 持仓历史保持原样。

Finance：侧栏“运行记录”；接口 `/api/ops/status` 与 `/api/ops/settings-history` 沿用原登录与访问限制。

ETF 本机只读查询：在 agent 目录运行 `python agent_ops.py --db ../state/operations.sqlite status`；`runs --run 2026-10-15:15:30` 可查指定窗口。

配置/研究/运行记录保存在各 Agent 自己的 operations SQLite 中，不共享凭据、不删除金融流水、不修改交易策略。归档摘要不会覆盖原始证据。未确认的消息应先人工对照 Telegram，不执行盲目重发。
