# ETF Agent V3

SMH / QQQ / SGOV · 2026-10-15 版 · 公开下载保持只读。

## 三只 ETF，三个市场阶段

正常：SMH 70%、QQQ 20%、SGOV 10%，容差为绝对 0.5 个百分点。主动买入 SGOV 止于 10%。SMH 与 QQQ 只买不卖。

回调：保留原 SMH 回调规则与 QQQ 评分曲线。先用已核实现金安排合格核心买入；SGOV 可以逐步增至最多 20%，这是上限，不是必须买满的目标。只有合格核心买入缺资金时，才卖 SGOV 补资。

复苏：按独立复苏条件买入核心 ETF。现金优先，然后分批释放 SGOV。最终将 SGOV 降至最多 5%，即使之前几轮已用现金买入，也要完成释放任务。趋势持续稳定、任务完成后，再用后续确认到账资金重建 SGOV 至 10%。

## 下载版能做什么

Mac 与 Windows App 包含新版三 ETF 规则、配置预览和原生只读账户验证。不会安装定时任务、启动实盘周期、模拟订单或提交订单。网站不能开启交易。

本机生产服务和公开桌面 App 的执行权限不同。一台电脑上的生产上线，不代表另一台电脑或账户已获授权。公开入口始终拒绝 --live，修改环境变量也不能开启。

## 开始使用

在 Tools 选择平台，完整解压 ZIP。Mac 打开 Averra Agent.app，验证自己的 Agent 密钥。内置 Python，需要 Apple Silicon 与 macOS 13 及以上；尚未经过 Apple 公证。

Windows 是在 Mac 上交叉编译的 x64 预览版。安装 .NET 8 Desktop Runtime x64，完整解压 ZIP，打开 AverraDesktop.exe。内置 Python；未签名，尚未完成真实 Windows 硬件验收。

选择已有 Codex MCP 配置，在那里登录自己的 Robinhood。连接 MCP 后，在正常交易时段运行只读账户验证。过期或缺失报价、未闭环意图、待批准订单与资金不一致都会阻断验证。下载包不包含任何人的密钥、账户或金融记录。

## 配比动画

网站沿用线框筹码托盘动画，增加 SMH、QQQ、SGOV 三只托盘。输入框与滑杆始终合计 100%；正常预设为 70 / 20 / 10。回调与复苏预设只是 SGOV 上限示意，不是每个阶段的固定目标。

自定义比例和复制的 JSON 只是一份浏览器草案，不覆盖已冻结策略或本机 App。恢复按钮会回到 70 / 20 / 10。

## 生产策略的资金与执行规则

经核实的 Robinhood Agentic limited-margin 账户允许复用合格的未结算卖出回款，不提供融资借款。采用当前现金与非杠杆购买力中的较低金额，留出费用缓冲；待入金未闭环时等待。不把预计 SGOV 卖款或历史回款再次加入现金。卖出成交核实后，重新读取现金才能计划后续买入。

生产窗口为美东 10:05、12:30、15:30。每日总买入与单笔上限为 $100，SGOV 每日卖出另设 $100 上限。每窗口最多一笔，整个账户最多一个未闭环意图。SMH 每日最多一次；QQQ 每日最多两次，并保留第一次成交闭环及第二次评分条件。只有 SGOV 可以卖出。

下单前重新检查账户、完整订单历史、持仓、资金、报价与券商预检查。审批在 Robinhood 完成。部分成交、待批准和未知订单保留预留；不重复提交不确定的请求。交易决策由固定代码执行，交易路径不调用 LLM。

## 换电脑

从 Tools 打开换机准备指南。先停止并确认旧执行器，保留当前账本、成交、预留与审计历史。本地恢复加密私人记录后，重新完成账户对账，才能考虑私人生产激活。不要用旧数据库覆盖新的金融事实。

公开 App 不会自动覆盖已有工作区。旧两 ETF 工作区需要迁移核对；可以另建 V3 只读工作区进行设置，保留旧记录。

## 历史研究与限制

公开日线数据区间为 2015-01-02 至 2026-10-13。研究使用完成收盘信号、下一交易日执行、相同的每月入金与单向 5 基点滑点。

时间加权最大回撤：动态循环 41.63%，固定 70 / 20 / 10 为 40.37%，原 80 / 20 规则为 43.10%。循环没有全面胜过对照。这是模拟研究，不是私人账户收益。

复权价研究隐含原 ETF 分红再投资，不能复现实际分红支付日现金、盘中波动率、税费、真实审批或券商成交。真实账户验证与固定代码测试是另一类证据；它们不认证新设备，也不保证未来收益。
